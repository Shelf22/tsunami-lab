# Tsunami Lab

A 3D tsunami and whirlpool sandbox for Windows.

**Install:** download `TsunamiLab-Windows.zip` from the [latest release](https://github.com/Shelf22/tsunami-lab/releases/latest), unzip the whole folder somewhere you can write to (Desktop, Documents), and double-click **Tsunami Lab.exe**.

It checks for updates every time you start it and installs new versions by itself.

The README inside the zip has the system requirements and controls.
