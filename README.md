# Tsunami Lab

A 3D tsunami and whirlpool sandbox for Windows and Linux.

Get it from the [latest release](https://github.com/Shelf22/tsunami-lab/releases/latest):

- **Windows:** download `TsunamiLab-Windows.zip`, unzip the whole folder somewhere you can write to (Desktop, Documents), and double-click **Tsunami Lab.exe**.
- **Linux:** download `TsunamiLab-Linux.tar.gz`, then `tar -xzf TsunamiLab-Linux.tar.gz` and run `./TsunamiLab/tsunami-lab` (add `--install-shortcut` once to put it in your applications menu).

Both check for updates every time you start them and install new versions by themselves. Windows and Linux always get the same version, so everyone can play together.

The README inside the download has the system requirements and controls.
